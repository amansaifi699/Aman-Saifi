A research-oriented medical imaging project that classifies chest X-ray images into four disease categories using **ResNet50 Transfer Learning** and **Grad-CAM Explainability**.

* Normal

* Explainable AI using Grad-CAM.
* TensorFlow/Keras implementation.
* Data preprocessing and augmentation.
* Confusion Matrix & Classification Report.
* Medical image visualization pipeline.

`Python` `TensorFlow` `ResNet50` `Grad-CAM`
